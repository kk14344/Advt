## 炼化最终奖励点击

炼化进度到 100% 时，助手打开游戏原生小游戏并自动点击到上限。点击优先走游戏自带的触摸模拟（`aandm.simTouch`，与新手引导同一条通路），并用游戏原生计数确认是否送达；连续两批没有增长时依次改用画布 pointer、touch、mouse，同时重新读取点击层。

点满 120 次或到达客户端上限（当前客户端为 100）后停止，等待原生倒计时结算。手动点过 1 次也不会卡住：助手从当前计数继续补到上限。结算成功后读取进度与过热度，确认都清零再补下一轮材料；材料仍按库存从多到少使用，每种默认保留 1,000 个。

## 冒险探险结果

一键日常会到冒险页领取探险结果：右侧剑图标旁的放大镜有可领宝箱时，按原生开箱流程领一次，等结果窗口出现后关闭并返回主界面。没有可领奖励时直接继续，不切换关卡，也不开启新的探索。

## 定时续跑开关

「营地设置 → 定时任务」里，「炼化自动续跑」与「矿车自动续跑」可以分别开关，新安装默认开启。关闭后该项已排的续跑立即取消，并同步 Windows 定时任务；正在执行的一轮会跑完，晚到的回执不会重新排期。重新开启后，等下一次实际执行结果再安排。两个开关只影响定时续跑，手动按钮和一键日常清单不受影响。

炼化续跑仍要求过热度严格低于 10% 才执行一轮日常；自动启动的窗口执行完后自动退出。

## 多开

在「营地设置 → 账号多开」勾选最多 4 个账号，点击「多账号同屏」。各账号使用自己的任务设置和队列。勾选的账号可一起接收助手任务，游戏内点击各自独立。

「日常清单 → 自动炼化及续跑」按库存从多到少加料。每种材料默认保留 1,000 个，可在「营地设置 → 助手设置 → 资源与宝箱」调整。

## 任务状态、记录与符文确认

- 「营地状态」显示正在等待的操作、状态和耗时。右上角「任务记录」可查日常结果和最近任务的消耗与收益。
- 「补办未完成项」针对结果单里的可补办事项，核对当日账号与游戏状态后执行。矿山和矿车倒计时也可通过任务栏托盘图标查看。
- 「营地设置 → 游戏偏好」可开启矿区标记。金色框标记目标，绿色框标记下一格，橙色框标记计划使用雷管的格子。
- 符文将消耗强化材料前，先显示出战页的可强化槽位、名称和等级。本轮只强化确认的一枚。日常强化仍使用一枚专用经验符文。最小化或窗口未激活时在状态栏等待选择。
- 「日常清单 → 矿山」可运行矿山护卫。按已选研究的材料缺口挑选当前列表中的对手，只使用游戏现有护卫次数。

## 矿山与矿车自动续跑

- 矿山本轮结束后，按最后一支在采矿队的成熟时间安排下一轮。续跑会重新确认所有在采矿队已成熟，再统一领奖、按勾选分支研究并派遣空闲矿队。没有待成熟矿队时，本轮结束。
- 矿车到站后先领取运送奖励，再沿用矿车设置发下一趟。用完运送次数且无法继续购买时结束。续跑只执行运送，拦截仍由原日常清单控制。
- 在「定时计划」可查看预计执行时间，分别开关矿山和矿车续跑。两项默认开启，运行中的其他任务完成后再继续。完全退出后，Windows 已登录时会到点启动助手，进入对应账号后继续。
- 所有定时启动都以最小化状态打开助手。助手已运行时，计划到点会在原窗口状态下执行。首次手动打开 1.37 时会更新已启用的 Windows 定时启动路径。

## 工坊

生产工坊和一键日常按设置的深度上限及精确时长选档。以默认 150 层、120 分钟为例，选中的是需要 120 层的深层 L2。开工前核对游戏深度，以及全部空位所需雷管和保留量。任一条件不足时，本轮生产跳过，营地状态显示所缺条件。收取已完成的工坊工程可照常执行。

## 符文

符文连抽优先十连，余额不足十连后切换为当前层单抽。十连每轮收取后强化已装备符文，单抽阶段在需要腾空位或水晶不足时强化。水晶付不起下一抽时完成剩余强化并结束。如果背包仍满，结束时说明容量原因。符文单轮最多抽取 100 次。

可用材料包括专用经验符文和闲置符文。所有出战页已装备的符文和已锁定符文受保护。“强化材料加入未锁定的闲置闪金符文”默认启用，可在「符文与宿命」设置中调整。

## 启动与性能

相同版本的公开启动分片按内容哈希保存在本机，下次打开游戏可直接复用。更新后按新哈希获取对应分片。定期清除较早的缓存，单一游戏来源约保留 192 MiB。游戏加载队列以及登录仍走原有流程。

每页只初始化一次助手脚本，设置一次同步。自动登录等原生按钮就绪后进入。任务推进由专用计时器负责，审计写盘在后台完成。

验证范围见随包记录。公共客户端只验证到登录画面。工坊和符文交易在离线回放和模拟中验证。

## 虚空裂隙

点击「开始虚空」后，先读取今日关卡、已有佣兵及每人的剩余出战次数、已装备符文。若初始免费佣兵尚未领取，先领取再评估。

整轮评估同时安排剩余所有关卡和末关第二次挑战。采用整轮配卡，同一佣兵每场只能占一个席位，全程不超过实际可出战次数，避免把末关必需的佣兵提前作为随意位消耗。遵守原攻略的角色顺序、品质、战力、先攻及周五回合限制，并优先评估技能触发更可靠的配卡。

阵容不足时，读取游戏当天的招募价格阶梯、实际剩余招募次数及血钻余额，只招募一次，然后重新评估整轮；满足攻略门槛即停止购买。血钻预算不设上限，仍受实际余额及服务器招募次数限制。招募被拒绝、回执异常、查询不完整或超时时不会重复付费。

正常关卡按顺序通关并领取佣兵。倒数第二关通关后保留该关佣兵，先挑战末关；首遍末关成功后再领取倒数第二关佣兵，并重新向服务器查询末关。只有服务器确认末关重新可挑战时才打第二遍，随后结束。若服务器要求先领奖或不再重置末关，则正常收尾，不更改或伪造关卡状态。每天的末关按当日配置确定，不固定为第六个地图。

符文只读取已装备效果用于评估，不自动换装。先攻同时考虑己方增益和敌方减益，敌方先攻按非负值估算，保留需要后手的攻略上限。对带长时间封印技能的 Boss 补充先手机制检查。周五若已装备符文会增加回合、破坏攻略的固定出手时序，会停止评估并说明原因，不为此继续招募。

本功能是原攻略与当前属性的门槛评估，不是完整战斗模拟。随机技能、服务器战斗逻辑及活动改动可能导致失利；同一关连续失败三次会结束本轮。实际奖励、末关重置和战斗胜负以服务器回执为准，尚未进行真实账号通关/收益测试。

## 符文连抽与强化

自动挖掘仍每次只开一个矿工包，确认次数增加后立即继续。勾选「拒绝耗时事件」时直接拒绝耗时奇遇，缺镐才补包；取消勾选时，每次操作前先补到至少 41 次，再接受奇遇。事件/魔像实际要求更高时按实际需求补充。日常和工坊仍保留大地之心优先、按计划批量补齐的方式。

「营地设置 → 助手设置 → 游戏偏好」的「自动挖矿镜头跟随」默认开启。仅在自动挖掘且处于矿区时调用游戏现有镜头接口，包含浅层下潜阶段。位置未变不刷新，连续移动限频。手动拖动/缩放时暂缓跟随；接口不支持或出错时只跳过镜头，挖矿与其他任务继续。可随时关闭。

开口的箱子（40号免费箱）是可清理的通路。接近魔像或其他目标时，若路径经过开口箱，就先免费开箱、确认清除后继续；不计为普通矿石，也不为它消耗雷管。即使未开启可选付费宝箱，仍可清理挡路的免费开口箱；查询回包若意外包含费用，会暂停该通路而不消耗钥匙。

可见魔像处于重试或冷却时，先处理其他可挑战的魔像；暂时都不能挑战时显示原因并暂停普通开挖，避免继续增加挖掘消耗。目标查询超时只重试读取；附近魔像标记已到但地图未到时先补读地形，新的地形或矿区代次会使旧坐标冷却失效。

已知目标使用实际最短可行通路，普通通路可用时先走普通通路；目标被红宝石等长时宝石或紫金岩封住时，即使未勾选「长矿用雷管」，也会按必要开口最少、雷管消耗较少的路线打通。红宝石等矿石按「定位开挖 → 确认 → 雷管 → 确认 → 收取 → 确认」继续；紫金岩按游戏原有点击即消耗雷管的方式处理。不会在同一个紫金岩后再发一次使用雷管。雷管不足时保留矿镐等待；回执缺失时只查询，不盲目重复消耗。

巨魔小怪和普通宝箱改按实际结算推进，移除起手0.9秒、结算1.2秒及额外0.4秒的固定延时。仍等待战斗原生回调与服务器地形确认；回执延迟、地图缓存缺失不算失败，不重复挑战或开箱。

镜头跟随的挖掘位置在画面内下移约一格，更靠近中央；实际挖掘坐标与坐标文字保持真实。

原有挖掘确认与服务器冷却继续保留：未发出的操作不建立等待，位置/地形已更新即可解除等待；漏回包时主动读取矿区状态，连续确认空闲后恢复，不因单笔回包缺失就直接停止。

## 按钮与炼化

助手自绘按钮统一为宽高3:1，使用选定的B版黑色文字：普通按钮固定10.5磅，大按钮固定13.5磅；只有放不下时才缩小。挖矿和一键日常并排，清单移至导航行，虚空两个按钮上下排列并与其他任务按钮协调。对应调整卡片、页签、收起/清空按钮、背景和留白。

日常炼化按库存从多到少排列可用材料，先扣除每种的保留量，再按游戏单件升温与剩余过热空间计算批量。每批确认后继续补剩余空间，进度满时进入最终奖励流程。

## 公会首领

挑战接口返回字面值 `failure` 时继续任务，短暂间隔后重新读取首领和许可证，再发起下一次挑战；该结果不计作成功攻击，不设固定重试次数。实际许可证不足、试炼结束或其他错误仍按真实状态收尾。未收到挑战回执的超时操作不会盲目重复。独立挑战和一键日常共用此逻辑。
