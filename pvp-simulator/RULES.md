## 2. 实服四维 0 误差计算规则（已通过 7 组实服样本 `0/0/0/0` 校验）

1. **基础加总顺序**：
   - `weapon_total_star[13]` + `title_bonus` + 30 格成员（宝具基础 + 宝具强化累计 + 2阶契约 + 主角契约 + 满突破双倍洗练）。
2. **被动技能两段结算（关键防重算规则）**：
   - **第一遍 (`take_special = nil`)**：
     - 累加全部主动/被动技能上的**固定四维**（`skill_info.{speed,defense,dodge,authority}`）。
     - 非 `is_special` 的普通被动立即生效；`is_special=True` 的被动按类型入队：
       - `effect_type ∈ {1,2,3,4}`（职业/性别/种族计数）插入 `special_skill_list` **队头**；
       - `effect_type == 5`（比例转换）插入 `special_skill_list` **队尾**；
       - `effect_type == 10`（阈值转换，如大巴娘 `360002`）插入 `special_skill_list2`。
   - **第二遍 (`take_special = true`)**：
     - 将 `special_skill_list2` 顺序追加到 `special_skill_list` 统一编号后依次执行。
     - **严禁再次累加固定四维**：`600013`（泉此方 +10 王者）、`600012`（时崎狂三 +15 闪避）、`600050`（宿大爷 +7 闪避）仅在第一遍加一次。
     - `effect_type == 5` 的比例转换统一采用 Lua `math.floor(src_num / param3 * num)`（含负除数如 `600015` `param3=-10` 向下取整），结果写入 `extra_*`，所有特殊技能结算完后再统一加回基础四维。
3. **符文生效时机**：
   - 游戏面板四维**不含符文**（出图底栏“属性”严格展示该值，与客户端 HUD 1:1 一致）。
   - 进战斗后，5 颗符文（允许同类 Lv20 线性叠加）在**被动转换之后**直接作用于己方/敌方四维，不再二次触发属性转换。

## 3. 实服战斗机制红线

1. **技能注册顺序**：合体主动技排在个人主动技**之前**，不受个人主动技总概率超 100% 挤占。
2. **封印规则**：`seal_turn` 按敌方行动递减；`seal_cond1` 为严格大于 `>`（`seal.lo=7` 不封 `7%`）。
3. **实服特例修正**：
   - `1400043`（魔法驳回）不触发 `effect_type=10` 封印；
   - `1800043`（无明）命中后封 `effect_type=13` 1 回合；
   - `70000010`（十一之弹，`reply_after_attack=True`）先按回复前战力结算伤害再回血；
   - `gm_combo_effects` 二段为纯粹攻击（`effect_type=13`，如 `70000055/70000082`）不插普攻、不闪避，先一段回复再按回复后战力结算二段纯粹伤害。

## 4. 标准化交付与出图流水线

每次修改规则、新增/优化阵容或对外交付，必须走统一门禁命令：

```powershell
# 1. 查看当前账号档案配置
python f:\antigra\pvp-simulator\sim.py profile

# 2. 一键标准交付（合规门禁 -> 0误差四维/覆盖率/合体技 -> 可选对手组对称评测 -> 自动1:1出图）
python f:\antigra\pvp-simulator\sim.py deliver <preset_or_json> --group top3_02_15_16 -n 500

# 3. 仅导出 1:1 原生素材阵容图（默认走 account_profile.json 的 server30）
python f:\antigra\pvp-simulator\sim.py export <preset_or_json>

# 4. 规则改动后的强制零误差回归门禁（7/7 全部通过，含 7 组实服四维 0/0/0/0 断言）
python f:\antigra\pvp-simulator\sim.py check
```
